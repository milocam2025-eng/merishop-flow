# Fase 14 — MeriShop instalable

La tienda pública funciona como una Progressive Web App (PWA).

## Comportamiento

- Se instala desde el navegador sin tienda de aplicaciones.
- El acceso abre directamente `/tienda`.
- Los clientes siguen comprando sin crear una cuenta.
- La protección administrativa y el acceso al inventario no cambian.
- Las páginas, el catálogo y las API siempre se consultan en línea para evitar datos desactualizados.

## Instalación

### Android (Chrome)

1. Abrir la tienda en Chrome.
2. Tocar **Instalar MeriShop**.
3. Confirmar **Instalar**.

### iPhone/iPad (Safari)

1. Abrir la tienda en Safari.
2. Tocar **Cómo instalar**.
3. Tocar **Compartir** y luego **Agregar a pantalla de inicio**.

La instalación definitiva debe realizarse desde el dominio de producción después de fusionar la fase.
